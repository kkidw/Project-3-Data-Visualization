# Project-3-Data-Visualization
# Global Wealth Distribution Interactive Visualization

## 📌 Project Overview
This project is a dynamic, interactive web application designed to visualize and rank the world's billionaires based on real-time datasets. The goal was to transform raw financial data into an accessible, user-friendly frontend interface that highlights market wealth concentration and supports market evaluation strategies.

## 🎯 Analytical Objective
To design an interactive frontend experience that allows users to easily explore global wealth distribution, filter key metrics, and visually understand economic disparities and market concentration at the highest levels of net worth.

## 🛠️ Tech Stack & Tools
* **Frontend:** HTML5, CSS3, JavaScript
* **Data Format:** JSON
* **Concepts:** DOM Manipulation, Interactive Data Visualization, Responsive Web Design

## 📊 Key Features
* **Interactive Ranking:** Users can view dynamically generated rankings of the world's billionaires.
* **Data-Driven UI:** The application parses JSON datasets to populate the interface without hardcoding values.
* **Responsive Design:** Built to ensure accessibility and clean visualization across different screen sizes.

## 💡 Business Impact
* Improved data accessibility for non-technical stakeholders by abstracting raw JSON data into a clean, visual format.
* Showcased capabilities in frontend development and interactive data presentation, which are critical for building executive-facing dashboards.

## 🚀 How to Run the Project
1. Clone this repository: `git clone https://github.com/kkidw/Project-3-Data-Visualization.git`
2. Navigate to the project directory.
3. Open `index.html` in your preferred web browser to view the interactive application.

## 📁 Repository Structure
* `/data`: Contains the JSON datasets used to populate the visualizations.
* `/css`: Stylesheets for UI formatting and layout.
* `/js`: JavaScript files handling data parsing and DOM manipulation.
* `index.html`: The main structural entry point for the web application.
